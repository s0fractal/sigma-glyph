# Reviewed claims about proofs/theorem_pins.json (enforced by
# proof_guard.registry_guard, which every bridge runs).
#
# Why this file exists: nothing hashed, anchored or cross-checked the pin
# registry, so `theorem_pins.json` authorized itself. Moving a theorem from a
# front's `guarded` list to `unguarded` — with an entirely plausible reason —
# and replacing it with `: True := trivial` passed every bridge green: the pin
# and the axiom cone were simply never consulted for it, and the only tell was
# a count inside a log line no gate greps (2026-07 round-3 review, F14).
#
# Round 4 then showed that COUNTS are not a claim about anything a reader
# cares about. Hiding `crystallization` from coverage, replacing it with
# `: True := trivial`, dropping it from `guarded`, and registering a fresh
# trivial `placeholder_bound` in its place kept every number equal — the whole
# diff of this file was the one `pins-sha256` line that `regen` rewrites on
# every run (F18). So the claims are now IDENTITIES, and they cover every
# field the guard's behaviour depends on:
#
#   * `core-modules <root>…` — the ONLY module roots whose constants may go
#     unpinned. The guard's audit scope is the complement of this, derived
#     from the kernel environment, so it cannot shrink by editing a per-front
#     list (F17).
#   * `front <name> build <mod>…` — the modules the bridge compiles AND the
#     guard queries. One list, read by both.
#   * `front <name> modules <mod>…` — what the environment query imports.
#   * `front <name> strict-sources|runner-sources <file>…` — what the source
#     layer audits, and at which profile.
#   * `front <name> axioms <ax>…` — that front's allowed axiom set.
#   * `front <name> guarded <Name>` — one line per theorem, so adding or
#     dropping one is a diff line that NAMES it.
#   * `front <name> native-decide-ok <Name>` — theorems allowed to rest on a
#     `native_decide` trust axiom at all.
#   * `front <name> native-decide-sources <Name>` — declarations allowed to
#     GENERATE such an axiom. A trust axiom used to be accepted on its shape
#     alone, from any declaration (F20). Each of these is statement-pinned.
#   * `unguarded <Name>` — the exact set of theorems deliberately outside the
#     axiom-cone check.
#   * `pins-sha256 <hex>` — the content hash of theorem_pins.json.
#     `proof_guard.py regen` refreshes THIS LINE ONLY; every identity above is
#     hand-written, and a registry edit that is not mirrored here fails.
#
# This is a review-visibility control, not an authority: anyone who can edit
# the registry can edit this file too. What it buys is that the edit is loud
# and names the theorem, instead of hiding inside a 30 000-line pin file.
